## 五层 AI 味框架（每次写中文前过一遍）

| 层 | 查什么 |
|---|---|
| 1 句法翻译腔 | 动词圈一遍：是不是 catch / sharp / break 的直译？"接住 / 锋利 / 不崩 / 狠 / 硬 / 锐"都算 |
| 2 词汇评价 | 有没有装腔单字（开干 / 撤 / 落盘）/ 充膨大词 / 身体感觉（痛 / 爽 / 丝滑）/ emoji |

| 4 态度姿态 | 有没有迎合 / 长篇认错表演 / 末尾确认反问 / 二极管（替 Ken 把条件性立场写成绝对规则）|
| 5 动机方法 | 写 PRD / 战略文档前，有没有先答商业模式 / 产品身份 / 长期路径三问题？有没有替 Ken 编战略叙事？|

## 鸭哥四套路（层 1 具体化，@grapeot 2026-04-18 分析）

1. **物理动作描述思考**——catch → 接住、sharp → 锋利、break → 崩、hold harder → 硬。**黑名单**：接住 / 击穿 / 拆解 / 收口 / 撑不住 / 不崩 / 不爆 / 狠 / 锋利 / 锐利 / 硬
2. **形容词 + 冒号抢判断**——"逻辑很清晰：" / "更干净：" 起手式。删形容词半句
3. **抽象名词做主语 + 形容词收尾**——"X 的 Y 比 Z 更 W"骨架，改成让人 / 动作做主语
4. **中英混合装专业**——有稳定译法的英文词（context / state / cache / claim）换回中文

**修法总则**：别修修补补，**重写**。读完原意盖上原句，用中文本来会怎么说，重说一遍。
