## 0. 内容层观察（n=20，读 transcript + summary，非结论）

### 0.1 反复出现的元结论（稳定 pattern）
- **"不存在单一学科能独立回答"**——几乎每一条都推出这个。baseline 架构下 agents 主动识别学科边界，不越界妄断
- **"拒绝二选一，动态化"**——决策类题几乎都推出（dec_02/03/07/10）
- **"价值能否通约" 是结构性 tension**：数学/CS/经济/物理（可量化派）vs 心理/社科/艺术人文（不可还原派）反复出现同类分歧。**这对 spec (d) 假设 "学科标签激发不同推理模式" 是弱正向信号**，但没对照组不能下结论——A 组去标签 pilot 是检验这个的关键

### 0.2 几条特别锐利的输出

| qid | 锐利输出 |
|---|---|
| prob_05（2030 AGI） | **"社会认证先于本体证明"**——区分 "被社会承认通过图灵测试" vs "真的 AGI" |
| str_03（独立 SaaS） | 经济学 vs 艺术人文："**不经现金流验证的叙事是破产前的审美胜利**" |
| eval_04（最宜创业国家） | "最适宜不是静态总分最高，是动态适应性最强" |
| dec_02（杭州买房） | "**'杭州房价'是 Simpson 悖论式聚合变量**，必须拆解到子市场" |
| cmp_07（三款新能源车） | 车 = "可进化技术系统 × 意义与文化载体" |
| prob_10（下次 PHEIC） | 物理相变临界点**挑战传统经济学 VaR 风险定价** |
| str_04（3 年生物科技上市） | **"元优化问题：当被优化者知道自己被优化时"**——Goodhart's law + Lucas critique |

这些都是真跨学科碰撞产出的内容，不是套话。

### 0.3 "未解决问题" 段产出的真科研问题（可直接作为 future work 引子）

- "如何为临界相变风险定价"（prob_10）
- "如何识别自主选择 vs 被结构美化的服从"（dec_10）
- "如何区分定义品类的叙事 vs 自嗨的故事"（str_03）
- "如何设计抗博弈的反身性 AGI 评估"（prob_05）

### 0.4 题型在**内容**上自然分化

| 题型 | 典型输出形态 |
|---|---|
| cmp（比较） | 多维分层评估框架，拒绝给唯一答案 |
| dec（决策） | 条件触发规则，拒绝二选一 |
| prob（概率） | 阈值识别 + 谨慎估计（"低概率但非极低"） |
| str（策略） | 受约束的序贯决策整合 |
| eval（评估） | 动态评估框架，非静态排名 |

**同一引擎在不同题型上自然走出不同输出结构**，说明 agents 对问题类型有区分能力。这**不只是成本差**（str 比 cmp 贵 22%），是输出结构差。

### 0.5 内容层隐忧

- **"单一学科不足 + 需要跨学科" 这个元结论稳定到过头**——可能是 agent prompt 内置倾向（"你的学科视角不可或缺" + "必须点名回应"）的直接产物，**不完全是涌现**。A 组去标签之后如果仍稳定出现这个元结论，才是真 signal。
- **学科分化 pattern 太干净**可能是刻板印象效应：数学/经济被 prompt "喂"了"你是量化派"的暗示，心理/艺术被"喂"了"你是不可还原派"。A 组对照必要。

## 2. 按题型细分

| 题型 | n | mean | stdev | 相对 cmp 溢价 |
|------|---|------|-------|--------------|
| cmp（比较题） | 5 | $0.9092 | $0.1744 | — |
| dec（决策题） | 4 | $0.8943 | $0.1689 | –1.6% |
| eval（评估题） | 3 | $1.0134 | $0.0845 | +11.5% |
| prob（概率题） | 3 | $1.0316 | $0.0693 | +13.5% |
| **str（策略题）** | 5 | **$1.1069** | $0.1960 | **+21.7%** |

**观察**：
- **策略题比比较题贵 22%**。大概率是策略题需要更多 reasoning 展开（多步方案、时间线、依赖关系），agent 用更多 token
- **评估题和概率题成本接近**（$1.01 vs $1.03），stdev 都窄（$0.07–$0.08），定价相对好预测
- **比较题和决策题接近**（$0.91 vs $0.89），是最"便宜"的两种

**对 spec.md 的含义**：如果全量 900 场按 5 题型均匀分布（每题型 180 场），总成本等于 mean × 900，不需要按题型分别外推——stdev $0.17 掩盖了题型差异，对总预算影响可忽略。
